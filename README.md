# DSH Prompt Kit

给 AI Agent 用的**结构化提示词模板**。核心思路：把「帮我做个视频」这类模糊需求，拆成可验收的工程契约。

## 目录

| 文件 | 用途 |
|---|---|
| [`prompts/data-viz-video.md`](prompts/data-viz-video.md) | 真实数据 → 动态图表视频（含数据契约、视觉规格、渲染管线、验收清单） |

## 为什么这样写

一句「用真实数据做个走势视频」交给 Agent，常见翻车点：

1. **编数据**——拿不到就"估算一下"，最后出来一条漂亮的假曲线
2. **一次性画完**——图上直接是完整折线，没有"时间推进"的叙事感
3. **口径漂移**——说好要"在售最低价"，做成了"成交均价"，数字差 20%
4. **无法复现**——渲染带随机/时间戳，同一秒重跑结果都不一样

对应地，模板把提示词拆成四层：

### 一、数据契约（最高优先级）

把"不许编数据"写成**可执行**的约束，而不是一句口号：

- 明确接口/页面与字段格式
- 明确时间粒度与聚合口径（每月取哪一天？缺失怎么办？）
- **缺口记 `null`，禁止插值、禁止拟合、禁止"约等于"**
- 原始响应必须落盘，供逐点核对
- **失败即停**：拿不到就停下说明，不许用模拟数据凑数

### 二、视觉规格

对齐参考视频的具体参数（画幅、帧率、时长、配色、版式），而不是"参考一下这个视频的样式"。
关键一条：**X 轴随时间逐帧推进**，不是一次性画完整曲线。

### 三、渲染管线

要求页面暴露 `window.__renderAt(t)`，保证**同一个 t 渲染结果完全一致**——
这样才能逐帧截图再合成，避免录屏抖动。同时规定交付物清单。

### 四、验收清单

让 Agent 自己检查：每个数字能否溯源？缺口是否列清？视频里每一帧的数值是否等于 CSV 里该月的值？

## 用法

把 `prompts/data-viz-video.md` 整段贴给具备「联网抓数 + 写代码 + 合成视频」能力的 Agent，按需改第五节的参数。

## 实战记录

这套模板用于 [cs2-skin-price-trend](https://github.com/) 项目时，实际拦下的问题：

- BUFF 接口硬上限 365 天 → 没有硬凑 2022 年数据，而是换了数据源并说明
- 2023-10 混进一个 ¥67 的异常成交 → 按月中位数过滤，过滤条数写进 CSV
- 蝴蝶刀 2024-12 整月无成交 → 图上留空，未插值
